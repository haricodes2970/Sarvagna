# Sarvagna Docs

Sarvagna is an AI powered VTU study companion. Students add subjects, scrape module notes, ask questions, and track progress with XP, levels, badges, and roadmaps. The backend exposes a FastAPI API and an agent based RAG pipeline. The frontend is a React single page app.

Tech stack (current):
- Backend: FastAPI, SQLAlchemy async, PostgreSQL, Redis, Qdrant, Celery, Ollama, Groq, Apify, Playwright
- Frontend: React (Vite), React Router, TanStack Query, Zustand, react-hot-toast
- Infra: Docker Compose for Postgres, Redis, Qdrant
